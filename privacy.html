개인정보처리방침

최종 개정: 2026년 8월 7일

레드라인(Redline, 이하 "채널")은 오프루트 스튜디오(OFFROUTE STUDIO)가 운영하는 채널로, 시사 콘텐츠를 제작하여 YouTube 등 플랫폼에 게시하는 콘텐츠 채널입니다. 본 방침은 채널의 웹사이트와 채널이 운영하는 소프트웨어(콘텐츠 업로드 자동화 도구)에 적용됩니다.

1. 수집하는 개인정보

본 웹사이트는 방문자의 개인정보를 수집하지 않습니다. 회원가입, 댓글, 쿠키, 추적 도구, 분석 도구를 사용하지 않습니다.

2. YouTube API 서비스 이용

채널은 자체 제작한 영상을 채널 운영자 본인의 YouTube 채널에 업로드하기 위해 YouTube API 서비스를 이용합니다. 이 과정에서:

  • API 클라이언트는 채널 운영자 본인의 계정에만 접근하며, 제3자(시청자·방문자)의 YouTube 계정 정보에 접근하지 않습니다.
  • 접근 권한은 영상 업로드(youtube.upload)로 한정됩니다.
  • 시청자의 개인정보를 수집·저장·공유하지 않습니다.

YouTube API 서비스 이용에는 Google 개인정보처리방침과 YouTube 서비스 약관이 적용됩니다.

3. 콘텐츠 제작에 관한 고지

채널의 영상 대본과 음성은 AI 기술을 활용해 제작되며, 이 사실은 각 영상의 설명란에 고지됩니다. 영상에 인용된 사실관계의 출처(언론 보도)는 각 영상의 고정 댓글에 공개됩니다.

4. 제3자 제공

수집하는 개인정보가 없으므로 제3자에게 제공하는 개인정보도 없습니다.

5. 문의

본 방침에 대한 문의는 YouTube 채널(@redline-issue)의 커뮤니티 탭 또는 채널 정보에 기재된 연락처로 해 주시기 바랍니다.

6. 방침의 변경

본 방침이 변경되는 경우 이 페이지를 통해 공지하며, 상단의 개정일을 갱신합니다.
